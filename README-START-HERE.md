# Operator build kit

1. Create an empty GitHub repo (e.g. `operator`) and put these files in it: `CLAUDE.md`, `PROMPT.md`, `docs/`, `playbooks/`.
2. Open Claude Code in a **cloud session** on that repo, so it runs on the $100 cloud credit rather than your Pro limits.
3. First message: **"Read CLAUDE.md, PROMPT.md and docs/RESEARCH_NOTES.md, then execute Phase 1 of PROMPT.md."**
4. It will stop and ask before anything irreversible, and finishes by writing `HANDOFF.md`.
5. Later, on Windows: clone the repo, follow `HANDOFF.md`, run `setup.bat`, dry-run the Notepad demo, then go live.

Before any real candidate data goes near it: get data protection sign-off at work (DPA/DPIA).
